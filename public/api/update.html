Actualizando la aplicación

Estamos retirando la versión antigua guardada por el navegador. Al terminar volverás al sistema con la corrección aplicada.

  • Quitando service workers antiguos
  • Borrando caché de la aplicación
  • Abriendo la versión actualizada
Este proceso no borra tus datos: clientes, facturas, inventario y configuración guardados en este dispositivo se conservan.

Si la página no redirige sola, abre la versión actualizada.
